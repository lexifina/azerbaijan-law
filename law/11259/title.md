Azərbaycan Respublikasının Əmək Məcəlləsinə dəyişiklik edilməsi barədə" Azərbaycan Respublikası Qanununun tətbiqi ilə əlaqədar Azərbaycan Respublikasının bəzi qanunvericilik aktlarında dəyişikliklər edilməsi haqqında
AZƏRBAYCAN RESPUBLİKASININ QANUNU
Azərbaycan Respublikasının Milli Məclisi qərara alır:
I. "Hərbi qulluqçuların statusu haqqında" Azərbaycan Respublikası Qanununun (Azərbaycan Respublikası Ali Sovetinin Məlumatı, 1992-ci il, N 4, maddə 79; 1993-cü il, N 5, maddə 132; Azərbaycan Respublikasının 1995-ci il 2 may tarixli 1030 nömrəli qanunu; Azərbaycan Respublikasının Qanunvericilik Toplusu, 1997-ci il, N5, maddə 378; 1998-ci il, N 1, maddələr 15, 16; 1999-cu il, N 4, maddə 228, N 5, maddə 286; 2001-ci il, N 6, maddələr 362, 363, N 11, maddə 694, N 12, maddələr 731, 736; 2004-cü il, N 2, maddə 57, N 3, maddə 133, N 4, maddələr 199, 212, N 7, maddə 507, N 8, maddə 596; Azərbaycan Respublikasının 2005-ci il 1 sentyabr tarixli 977-II QD nömrəli Qanunu) 21-ci maddəsinin 1-ci bəndinin "ğ)" yarımbəndində "müavinətlər ödənilməsi (iş yeri üzrə)" sözləri "Azərbaycan Respublikasının Əmək Məcəlləsinin 74-cü maddəsinə uyğun olaraq müavinətlər ödənilməsi" sözləri ilə əvəz edilsin.
II. "İnsanın immunçatışmazlığı virusunun törətdiyi xəstəliyin (AİDS) yayılmasının qarşısının alınması haqqında" Azərbaycan Respublikası Qanununun (Azərbaycan Respublikasının Qanunvericilik Toplusu, 1997-ci il, N 2, maddə 94, N 5, maddə 382; 2001-ci il, N 12, maddə 731; 2002-ci il, N 6, maddə 328) 13-cü maddəsinin birinci hissəsinin ikinci abzasında "Azərbaycan Respublikasının qanunvericiliyində müəyyən edilmiş qaydada dövlət sosial sığorta vəsaiti almaq" sözləri "Azərbaycan Respublikasının Əmək Məcəlləsinin 74-cü maddəsinə uyğun olaraq müavinət almaq" sözləri ilə əvəz edilsin. [^1]
III. "Məcburi köçkünlərin və onlara bərabər tutulan şəxslərin sosial müdafiəsi haqqında" Azərbaycan Respublikası Qanununun (Azərbaycan Respublikasının Qanunvericilik Toplusu, 1999-cu il, N 7, maddə 393; 2001-ci il, N 12, maddələr 731, 736) 8-ci maddəsinin ikinci hissəsində "sosial sığorta ödəmələri" sözləri "Azərbaycan Respublikasının Əmək Məcəlləsinin 74-cü maddəsinə uyğun olaraq müavinət" sözləri ilə əvəz edilsin.
IV. "Azərbaycan Respublikasında vərəmlə mübarizə haqqında" Azərbaycan Respublikası Qanununun (Azərbaycan Respublikasının Qanunvericilik Toplusu, 2000-ci il, N 7, maddə 484; 2001-ci il, N 12, maddə 736; 2002-ci il, N 6, maddə 328) 14-cü maddəsinin üçüncü hissəsinin birinci cümləsində “əmək haqqı 100%" sözləri "Azərbaycan Respublikasının Əmək Məcəlləsinin 74-cü maddəsinə uyğun olaraq müavinət əmək haqlarının 100 faizi" sözləri ilə əvəz edilsin".
V. Bu qanun dərc edildiyi gündən qüvvəyə minir.
