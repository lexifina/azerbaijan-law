Maddə 144. Mənzil fondu istismarının və təmirinin maddi-texniki təminatı
SSR İttifaqının və müttəfiq respublikaların mənzil qanunvericiliyi Əsaslarına uyğun olaraq dövlət və ictimai mənzil fondunun, mənzil-tikinti kooperativləri fondunun istismarı və təmiri; üçün lazım olan maddi-texniki ehtiyatlar bunların məsrəfi normalarına uyğun olaraq, SSRİ Nazirlər Sovetinin müəyyən etdiyi qaydada Azərbaycan SSR Nazirlər Sovetinə, SSRİ nazirliklərinə, dövlət komitələrinə və baş idarələrinə ayrılır. [^1]
V BÖLMƏ
MƏNZİL QANUNVERİCİLİYİNİ POZMAĞA GÖRƏ MƏSULİYYƏT

[^1]: 25 oktyabr 1985-ci il tarixli 208—XI nömrəli “Azərbaycan SSR Mənzil məcəlləsinə dəyişiklik və əlavələr edilməsi haqqında” Azərbaycan SSR Ali Soveti Rəyasət Heyətinin Fərmanı (Azərbaycan Respublikasının Ali Sovetinin Məlumatı, 1985-ci il, № 19-20, maddə 195) ilə 144-cü maddədə “müttəfiq respublikaların Nazirlər Sovetlərinə” sözləri “Azərbaycan SSR Nazirlər Sovetinə” sözləri ilə əvəz edilmişdir.
