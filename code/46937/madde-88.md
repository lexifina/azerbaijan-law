Maddə 88. Yaşayış sahəsini icarə müqaviləsinin kirayədarın tələbi ilə pozulması
Uçmaq qorxusu olan evlərdən çıxarma halları istisna olmaqla, dövlət və ictimai mənzil fondu evlərində yaşayış sahəsini icarə müqaviləsi kirayədarın tələbi ilə yalnız qanunla müəyyən edilmiş əsaslar üzrə və ancaq məhkəmə qaydasında pozula bilər. [^1]

[^1]: Bax: 15-ci istinad
