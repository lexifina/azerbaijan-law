Maddə 174. Nikahın qeydə alınması
Nikahın qeydə alınması müvafiq icra hakimiyyəti orqanı tərəfindən nikaha daxil olan şəxslərin iştirakı ilə aparılır.[^1]

[^1]: 22 oktyabr 2002-ci il tarixli 374-IIQD nömrəli “Azərbaycan Respublikasının Ailə Məcəlləsinə dəyişikliklər və əlavələr edilməsi haqqında” Azərbaycan Respublikasının Qanunu (Azərbaycan Respublikasının qanunvericilik toplusu, 2002-ci il, № 12, maddə 702) ilə 174-cü maddədə “orqanında” sözü “orqanı tərəfindən” sözləri ilə əvəz edilmişdir.
