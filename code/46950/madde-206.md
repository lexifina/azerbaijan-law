Maddə 206. Törədilmiş və ya hazırlanan cinayətlər haqqında media subyektlərinin məlumatları[^1]
206.1. Cinayətin törədilməsi və ya onun törədilməsinə hazırlıq faktına dair müvafiq media subyektinə məlum olmuş, cinayət işinin başlanması üçün səbəb hesab edilən media subyektlərinin məlumatları mətbuatda, radioda, televiziyada əks etdirildikdən sonra cinayət təqibi orqanlarına göndərilməlidir.
206.2. Törədilmiş və ya hazırlanan cinayətlərlə əlaqədar media subyektlərinə ünvanlanmış, dərc edilməmiş yazışmalar media subyektlərinin vəzifəli şəxsləri tərəfindən bu Məcəllənin 205-ci maddəsində nəzərdə tutulmuş qaydada cinayət təqibi orqanlarına göndərilə bilər.
206.3. Törədilmiş və ya hazırlanan cinayətlər haqqında məlumatları dərc etmiş və ya aidiyyəti üzrə göndərmiş media subyektlərinin vəzifəli şəxsləri, habelə həmin məlumatların müəllifləri onlarda olan və cinayət haqqında məlumatı təsdiq edən sənədləri təhqiqatçı ya, müstəntiq, ibtidai araşdırmaya prosessual rəhbərliyi həyata keçirən prokurora və ya məhkəməyə təqdim etməlidirlər.

[^1]: 17 fevral 2023-cü il tarixli 807-VIQD nömrəli Azərbaycan Respublikasının Qanunu ilə 206-cı maddənin adında, 206.1-ci, 206.2-ci (hər iki halda), 206.3-cü maddələrdə ismin müvafiq hallarında “kütləvi informasiya vasitələri” sözləri ismin müvafiq hallarında “media subyektləri” sözləri ilə əvəz edilmişdir.
