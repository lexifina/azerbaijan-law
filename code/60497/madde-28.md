Maddə 28. Vəzifədən çıxarma
Məhkumun tutduğu vəzifədə qalmasını qeyri-mümkün hesab etdikdə məhkəmə vəzifədən çıxarma cəzası tətbiq edə bilər (Azərbaycan SSR Ali Soveti Rəyasət Heyətinin 1985-ci il 14 noyabr tarixli fərmanı redaksiyasında — Azərbaycan SSR Ali Sovetinin Məlumatı, 1985-ci il, № 21, maddə 204).
