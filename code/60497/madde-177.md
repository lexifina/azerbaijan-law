Maddə 177. İfadə verməyə məcbur etmə
Təhqiqat və ya ibtidai istintaq aparan şəxs tərəfindən dindirmə zamanı hədə-qorxu gəlmə və ya sair qanunsuz hərəkətlər tətbiq etmə yolu ilə ifadə verməyə məcbur etmə—
üç ilədək müddətə azadlıqdan məhrumetmə ilə cəzalandırılır.
Eyni hərəkətlər zor tətbiq etməklə və ya dindirilən şəxsi ələsalma ilə edildikdə—
üç ildən səkkiz ilədək müddətə azadlıqdan məhrumetmə ilə cəzalandırılır.
