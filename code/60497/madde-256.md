Maddə 256. Müharibə aparma vasitələrini düşmənə vermə və ya düşmən üçün qoyub getmə
Rəisin ona etibar edilib tapşırılmış hərbi qüvvələri düşmənə verməsi, habelə istehkamları, döyüş texnikasını və müharibə aparma üçün olan başqa vasitələri heç də döyüş şəraitinin tələb etmədiyi halda düşmən üçün qoyub getməsi düşmənə kömək etmə məqsədilə edilməmişdirsə—
üç ildən on ilədək müddətə azadlıqdan məhrumetmə və ya ölüm cəzası ilə cəzalandırılır.
