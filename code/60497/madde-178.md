Maddə 178. Bilə-bilə yalan xəbərçilik etmə
Cinayət edilməsi haqqında bilə-bilə yalan xəbərçilik etmə—
üç ilədək müddətə azadlıqdan məhrumetmə ilə cəzalandırılır.
Eyni hərəkətlər xüsusi təhlükəli dövləti cinayətdə və ya sair ağır cinayətdə ittiham etməklə əlaqədar olaraq edildikdə və ya tamah məqsədilə edildikdə, yaxud süni surətdə ittiham sübutları düzəltməklə edildikdə—
üç ildən səkkiz ilədək müddətə azadlıqdan məhrumetmə ilə cəzalandırılır (Azərbaycan SSR Ali Soveti Rəyasət Heyətinin 1982-ci il 22 dekabr tarixli fərmanı redaksiyasında — Azərbaycan SSR Ali Sovetinin Məlumatı, 1982-ci il, № 24, maddə 292).
