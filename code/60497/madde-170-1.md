Maddə 170-1. Rüşvətxorluqda vasitəçilik
Rüşvətxorçuluqda vasitəçilik—
iki ildən səkkiz ilədək müddətə azadlıqdan məhrumetmə ilə cəzalandırılır.
Rüşvətxorluqda dəfələrlə vasitəçilik etmə və ya rüşvətxorluğa görə əvvəllər məhkum olunmuş şəxsin vasitəçilik etməsi və ya qulluq mövqeyindən istifadə edərək vasitəçilik etmə—
əmlakı müsadirə olunmaqla və azadlıqdan məhrum olunmanı çəkib qurtardıqdan sonra iki ildən beş ilədək müddətə sürgün edilməklə və ya sürgün edilməməklə yeddi ildən on beş ilədək müddətə azadlıqdan məhrumetmə ilə cəzalandırılır (Azərbaycan SSR Ali Soveti Rəyasət Heyətinin 1962-ci il 28 fevral tarixli fərmanı ilə əlavə edilmişdir — Azərbaycan SSR Ali Sovetinin Məlumatı, 1962-ci il, № 7, maddə 31).
