Maddə 201. Qırmızı Xaç və Qırmızı Aypara nişanlarından qanunsuz olaraq istifadə etmə
Qırmızı Xaç və Qırmızı Aypara emblemalarından, fərqləndirici nişanlarından və adlarından qanunsuz olaraq istifadə etmə—
bir ilədək müddətə azadlıqdan məhrumetmə və ya eyni müddətə islah işləri ilə və ya ictimai məzəmmətlə cəzalandırılır.
