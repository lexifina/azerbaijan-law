Maddə 64. Müharibə təbliğatı
Hər hansı formada olursa-olsun müharibə təbliğatı aparma—
iki ildən beş ilədək müddətə sürgün edilməklə və ya sürgün edilməməklə üç ildən səkkiz ilədək müddətə azadlıqdan məhrumetmə ilə cəzalandırılır (Azərbaycan SSR Ali Soveti Rəyasət Heyətinin 1961-ci il 24 iyul tarixli fərmanı redaksiyasında — Azərbaycan SSR Ali Sovetinin Məlumatı, 1961-ci il, № 21, maddə 78).
