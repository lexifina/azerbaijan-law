Maddə 244. Öz bədəninə xəsarət yetirmə yolu ilə və ya sair üsulla hərbi qulluqdan boyun qaçırma
a) Hərbi qulluqçunun özünə hər hansı xəsarət yetirməsi və ya özünü xəstəliyə vurma, sənədləri saxtalaşdırma yolu ilə və ya sair aldatma yolu ilə hərbi qulluq vəzifələrini çəkməkdən boyun qaçırması, habelə hərbi qulluq vəzifələrini çəkməkdən imtina etməsi—
üç ildən yeddi ilədək müddətə azadlıqdan məhrumetmə ilə cəzalandırılır.
b) Eyni əməllər müharibə vaxtı və ya döyüş şəraitində törədilərsə—
ölüm cəzası və ya beş ildən on ilədək müddətə azadlıqdan məhrumetmə ilə cəzalandırılır.
