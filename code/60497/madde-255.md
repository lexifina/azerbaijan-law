Maddə 255. Hakimiyyətdən sui-istifadə etmə, hakimiyyət həddini aşma və ya hakimiyyətdən istifadə etməmək
a) Rəisin və ya vəzifəli şəxsin hakimiyyətdən və ya qulluq mövqeyindən sui- istifadə etməsi, hakimiyyət həddini və ya qulluq səlahiyyətini aşması, hakimiyyətdən istifadə etməməsi, müntəzəm, yaxud tamahkarlıq məqsədilə və ya digər şəxsi marağa görə edilmişsə, habelə bu əməllər ciddi zərər vurmuşsa—
beş ilədək müddətə azadlıqdan məhrumetmə ilə cəzalandırılır.
b) Ağır nəticələrə səbəb olmuş eyni əməllər—
üç ildən on ilədək müddətə azadlıqdan məhrumetmə ilə cəzalandırılır.
v) Bu maddənin «a» və «b» bəndlərində nəzərdə tutulmuş əməllər müharibə vaxtı və ya döyüş şəraitində törədildikdə—
beş ildən on beş ilədək müddətə azadlıqdan məhrumetmə ilə cəzalandırılır (Azərbaycan SSR Ali Soveti Rəyasət Heyətinin 1984-cü il 1 fevral tarixli fərmanı redaksiyasında — Azərbaycan SSR Ali Sovetinin Məlumatı, 1984-cü il, № 3-4, maddə 29).
