Maddə 68. Gəmilərin dəniz bələdçisi ilə keçirilməsinin məcburi və məcburi olmayan rayonlarının müəyyənləşdirilməsi
Gəmilərin dəniz bələdçisi ilə keçirilməsinin məcburi və məcburi olmayan rayonlarını müvafiq icra hakimiyyəti orqanı müəyyən edir və belə rayonlar dəniz limanının məcburi qaydaları, losiyalar və informasiya bülletenləri ilə hamının nəzərinə çatdırılır.
