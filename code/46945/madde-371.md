Maddə 371. Yeni sübutların təqdim edilməsi
371.1. İşdə iştirak edən şəxslər apellyasiya məhkəməsinə yeni sübutlar təqdim edə bilərlər.
371.2. Apellyasiya instansiyası məhkəməsi tərəfin birinci instansiya məhkəməsinə təqdim edə bilmədiyi yeni sübutları gecikmiş və ya apellyasiya prosesini ləngitməyə yönəlmiş və yaxud kobud səhlənkarlığa görə təqdim edilməmiş hesab etdikdə, onları rədd edə bilər.
