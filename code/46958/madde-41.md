Maddə 41. Məlumat vermək vəzifəsi
Mülkiyyətçilər və digər maraqlı şəxslər, habelə onların müvəkkil etdiyi şəxslər müvafiq icra hakimiyyəti orqanına və ya bələdiyyəyə müvafiq ərazinin abadlaşdırılmasına ehtiyacın qiymətləndirilməsi və ya həyata keçirilməsi ilə bağlı zəruri faktlar barədə məlumat vermək öhdəliyi daşıyırlar.
