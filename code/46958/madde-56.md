Maddə 56. Tikinti materiallarının və məmulatının əvəzlənməsi qaydası
Tikinti materiallarının və məmulatının uyğun xassəli digər tikinti materialları və məmulatı ilə əvəzlənməsi tikintinin layihəçisi və sifarişçisi ilə razılaşdırılır. Tikinti materiallarının və məmulatının fərqli xassəli materiallarla və məmulatla əvəzlənməsi üçün tikintiyə icazə vermiş orqanın icazəsi tələb olunur.
