Maddə 16. Şəhərsalma və tikinti fəaliyyətinin vahid informasiya təminatı sistemi
16.1. Ərazinin kompleks qiymətləndirilməsini, şəhərsalma və tikinti fəaliyyəti sahəsində müvafiq qərarların qəbul edilməsini təmin etmək məqsədi ilə şəhərsalma və tikinti fəaliyyətinin vahid informasiya təminatı sistemi təşkil edilir.
16.2. Şəhərsalma və tikinti fəaliyyətinin vahid informasiya təminatı sisteminin təşkili və fəaliyyəti qaydası, eləcə də sistemə daxil edilən məlumatların tərkibi, həmin məlumatların təqdim edilməsi və işlənilməsi qaydaları müvafiq icra hakimiyyəti orqanı tərəfindən müəyyən edilir.
