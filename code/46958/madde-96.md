Maddə 96. Tikintiyə nəzarətin məqsədi və növləri
96.1. Tikintiyə nəzarətin məqsədi obyektin şəhərsalma və tikintiyə dair normativ sənədlərin tələblərinə əməl olunmaqla tikilməsini təmin etməkdən ibarətdir.
96.2. Tikintiyə nəzarətin aşağıdakı növləri vardır:
96.2.1. dövlət nəzarəti;
96.2.2. texniki nəzarət;
96.2.3. müəllif nəzarəti;
96.2.4. daxili əməliyyat nəzarəti.
