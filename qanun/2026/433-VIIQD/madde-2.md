Maddə 2. “İctimai iştirakçılıq haqqında” Azərbaycan Respublikasının Qanununda (Azərbaycan Respublikasının Qanunvericilik Toplusu, 2014, № 1, maddə 1 (Cild I) aşağıdakı dəyişikliklər edilsin:
2.1. 6.3-cü maddənin birinci cümləsində “öz internet səhifəsi” sözləri “özünün rəsmi internet informasiya ehtiyatı, Elektron Hökumət İnformasiya Sistemi (bundan sonra – EHİS)” sözləri ilə əvəz edilsin;
2.2. 14.2-ci maddədə “səhifəsində” sözü “informasiya ehtiyatında” sözləri ilə əvəz edilsin və həmin maddəyə “mediada” sözündən sonra “, habelə EHİS-də” sözləri əlavə edilsin;
2.3. 15.1-ci və 15.2-ci maddələrə “təqdim olunur” sözlərindən sonra “(o cümlədən EHİS vasitəsilə)” sözləri əlavə edilsin;
2.4. 16.1-ci maddədə “öz internet səhifəsində” sözləri “özünün rəsmi internet informasiya ehtiyatında” sözləri ilə əvəz edilsin və həmin maddəyə “mediada” sözündən sonra “, habelə EHİS-də” sözləri əlavə edilsin;
2.5. 17-ci maddə üzrə:
2.5.1. 17.1-ci maddəyə “verə bilməsi” sözlərindən sonra “(o cümlədən EHİS vasitəsilə)” sözləri əlavə edilsin;
2.5.2. 17.2-ci maddəyə “dərc edilir” sözlərindən sonra “(o cümlədən EHİS vasitəsilə)” sözləri əlavə edilsin;
2.6. 18-ci maddə üzrə:
2.6.1. 18.2.1-ci maddədə “internet səhifəsində” sözləri “rəsmi internet informasiya ehtiyatında” sözləri ilə əvəz edilsin;
2.6.2. 18.2.2-ci və 18.2.3-cü maddələrdə “internet səhifəsinin” sözləri “rəsmi internet informasiya ehtiyatının” sözləri ilə əvəz edilsin və həmin maddələrə “bölməsində” sözündən sonra “və EHİS-də” sözləri əlavə edilsin;
2.6.3. 18.2.4-cü maddəyə “məlumatlandırır” sözündən sonra “(o cümlədən EHİS vasitəsilə)” sözləri əlavə edilsin;
2.6.4. 18.2.5-ci maddəyə “dərc edir” sözlərindən sonra “(o cümlədən EHİS vasitəsilə)” sözləri əlavə edilsin;
2.7. 19-cu maddəyə aşağıdakı məzmunda ikinci cümlə əlavə edilsin:
“Hüquqi aktların layihələrinə dair ictimai dinləmənin və ictimai müzakirənin elektron qaydada təşkili eyni zamanda EHİS vasitəsilə təmin edilir.”.
