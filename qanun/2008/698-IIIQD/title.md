"Bələdiyyələrin əraziləri və torpaqları haqqında" Azərbaycan Respublikasının Qanununa əlavə edilmiş "Azərbaycan Respublikasında bələdiyyələrin siyahısı"nda, "Bələdiyyə torpaqlarının idarə edilməsi haqqında" və "Azərbaycan Respublikasının 2008-ci il dövlət büdcəsi haqqında" Azərbaycan Respublikasının qanunlarında dəyişikliklər edilməsi barədə
AZƏRBAYCAN RESPUBLİKASININ QANUNU
Azərbaycan Respublikasının Milli Məclisi qərara alır:
I. "Bələdiyyələrin əraziləri və torpaqları haqqında" Azərbaycan Respublikasının Qanununa (Azərbaycan Respublikasının Qanunvericilik Toplusu, 1999-cu il, № 12, maddə 689; 2001-ci il, № 11, maddə 677; 2002-ci il, № 5, maddə 237; 2003-cü il, № 6, maddə 273, № 8, maddə 419; 2004-cü il, № 7, maddə 522, № 10, maddə 784, № 12, maddələr 982, 987; 2005-ci il, № 4, maddə 283, № 10, maddə 884; 2007-ci il, № 3, maddə 212, № 11, maddə 1051; 2008-ci il, № 5, maddələr 346, 347; Azərbaycan Respublikasının 2008-ci il 4 iyul tarixli 667-IIIQD nömrəli qanunu) əlavə edilmiş "Azərbaycan Respublikasında bələdiyyələrin siyahısı"nda aşağıdakı dəyişikliklər edilsin:
1. "Əli Bayramlı şəhəri" bölməsinin adında və həmin bölmənin 1-ci sırasında "Əli Bayramlı" sözləri "Şirvan" sözləri ilə əvəz edilsin;
2. "Xanlar rayonu" bölməsinin adında "Xanlar rayonu" sözləri "Göygöl rayonu" sözləri ilə və həmin bölmənin 1-ci sırasında "Xanlar bələdiyyəsi" və "Xanlar şəhəri" sözləri müvafiq olaraq "Göygöl bələdiyyəsi" və "Göygöl şəhəri" sözləri ilə əvəz edilsin;
3. "Qobustan rayonu" bölməsinin 1-ci sırasında "Mərəzə bələdiyyəsi" sözləri "Qobustan bələdiyyəsi" və "Mərəzə qəsəbəsi" sözləri "Qobustan şəhəri" sözləri ilə əvəz edilsin və həmin bölmənin 18-ci sırası çıxarılsın;
4. "Lerik rayonu" bölməsinin 1-ci sırasında "Lerik qəsəbəsi" sözləri "Lerik şəhəri" sözləri ilə əvəz edilsin;
5. "Samux rayonu" bölməsinin 1-ci sırasında "Nəbiağalı bələdiyyəsi" və "Nəbiağalı qəsəbəsi" sözləri müvafiq olaraq "Samux bələdiyyəsi" və "Samux şəhəri" sözləri ilə əvəz edilsin və həmin bölmənin 16-cı sırası çıxarılsın;
6. "Yardımlı rayonu" bölməsinin 1-ci sırasında "Yardımlı qəsəbəsi" sözləri "Yardımlı şəhəri" sözləri ilə əvəz edilsin və həmin bölmənin 16-cı və 21-ci sıraları çıxarılsın.
II. "Bələdiyyə torpaqlarının idarə edilməsi haqqında" Azərbaycan Respublikası Qanununun (Azərbaycan Respublikasının Qanunvericilik Toplusu, 2001-ci il, № 8, maddə 520; 2004-cü il, № 5, maddə 314; 2005-ci il, № 2, maddə 62, 2006-cı il, № 6, maddə 486, № 11, maddə 923; 2007-ci il, № 11, maddə 1082; 2008-ci il, № 5, maddə 348, № 6, maddə 462) 8.0.1-ci maddəsində "Əli Bayramlı" sözləri "Şirvan" sözü ilə əvəz edilsin.
III. "Azərbaycan Respublikasının 2008-ci il dövlət büdcəsi haqqında" Azərbaycan Respublikası Qanununun (Azərbaycan Respublikasının Qanunvericilik Toplusu, 2007-ci il, № 12, maddə 1198; 2008-ci il, № 5, maddə 357) 13-cü maddəsindəki cədvəlin "Şəhər və rayonların adı" sütununun 2-ci bəndində "Əli Bayramlı" sözləri "Şirvan" sözü ilə və 56-cı bəndində "Xanlar" sözü "Göygöl" sözü ilə əvəz edilsin.
IV. Bu Qanun dərc edildiyi gündən qüvvəyə minir.
İlham ƏLİYEV,
Azərbaycan Respublikasının Prezidenti
Bakı şəhəri, 2 oktyabr 2008-ci il.
