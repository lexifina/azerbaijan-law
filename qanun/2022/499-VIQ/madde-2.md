Maddə 2
1. Azərbaycan Respublikası və Gürcüstan arasında dövlət sərhədini keçmək üçün aşağıdakı buraxılış məntəqələri müəyyən edirlər:
a) daimi, beynəlxalq sərnişin və yük əlaqələri üçün
 | dəmir yolu:
“Böyük-Kəsik” | - | Qardabanı
(Azərbaycan Respublikası) |  | (Gürcüstan)
 | avtomobil:
“Qırmızı Körpü” | - | “Krasmy most”
(Azərbaycan Respublikası) |  | (Gürcüstan)
“Mazımqara” | - | Tsodna
(Azərbaycan Respublikası) |  | (Gürcüstan)
b) daimi avtomobil, sərnişin və yük əlaqələri üçün birgə, beynəlxalq avtomobil buraxılış məntəqəsi:
“İpək Yolu” | - | “Abreşumis Qza”
(Azərbaycan Respublikası) |  | (Gürcüstan)
v) daimi, dövlətlərarası sərnişin və yük əlaqələri üçün
 | piyadalar üçün avtomobil:
“Sadıxlı” | - | “Vaxtangisi”
(Azərbaycan Respublikası) |  | (Gürcüstan)
q) mövsümi dövlətlərarası, sərnişin və yük əlaqələri üçün yalnız sərhədyanı rayonlarda yaşayan vətəndaşlar üçün (yay vaxtı buraxılış rejimi saat 08:00-dan 21:00-dək, qış vaxtında 08:00-dan 18:00-dək)
 | piyadalar üçün avtomobil:
“Muğanlı” | - | “Samtatskaro”
(Azərbaycan Respublikası) |  | (Gürcüstan)
2. Azərbaycan Respublikası ilə Gürcüstan arasında beynəlxalq əlaqələrə açıq olan aeroportlarda əlaqə və beynəlxalq poçt mübadiləsi yerlərində və məntəqələrində beynəlxalq poçt mübadiləsi Tərəflərin dövlətlərinin iştirakçısı olan ikitərəfli, habelə beynəlxalq və çoxtərəfli sazişlər əsasında həyata keçiriləcəkdir.
3. Tərəflər bu maddədə qeyd olunan buraxılış məntəqələrində nəzarət xidmətlərinin normal fəaliyyət göstərməsi üçün lazımi olan şərait və infrastrukturu təmin edəcəklər.
4. Tərəflərin səlahiyyətli orqanları ayrı-ayrı protokollarla “İpək Yolu” - “Abreşumis Qza” birgə buraxılış məntəqəsindən daşman mal və nəqliyyat vasitələri ilə bağlı sərhəd və gömrük prosedurlarının tətbiq olunma prinsiplərini müəyyən edəcəklər.
