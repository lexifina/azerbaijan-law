Hərbi qulluqçuların pensiya təminatı haqqında" Azərbaycan Respublikasının Qanununa dəyişikliklər və əlavə edilməsi barədə" Azərbaycan Respublikası Qanununun tətbiqi ilə əlaqədar Azərbaycan Respublikasının bəzi qanunvericilik aktlarına dəyişikliklər edilməsi haqqında
AZƏRBAYCAN RESPUBLİKASININ QANUNU
Azərbaycan Respublikasının Milli Məclisi qərara alır:
I. "Hərbi qulluqçuların statusu haqqında " Azərbaycan Respublikası Qanununun (Azərbaycan Respublikası Ali Sovetinin məlumatı, 1992-ci il, N 4, maddə 79; 1993-cü il, N 5, maddə 132; Azərbaycan Respublikasının 1995-ci il 2 may tarixli 1030 nömrəli qanunu; Azərbaycan Respublikasının Qanunvericilik Torlusu, 1997-ci il, N 5, maddə 378; 1998-ci il, N 1, maddələr 15,16; 1999-cu il, N 4, maddə 228, N 5, maddə 286; 2001-ci il, N6, maddələr 362, 363, N 11, maddə 694, N 12, maddələr 731, 736; 2004-cü il, N 2, maddə 57, N 3, maddə 133, N 4, maddələr 199, 212, N7, maddə 507, N 8, maddə 596) 10-cu maddəsinin 2-ci bəndinin birinci abzasının üçüncü cümləsi aşağıdakı redaksiyada verilsin:
"Döyüş şəraitində döyüş əməliyyatlarında iştirak edən hərbi qulluqçuların həmin dövr üçün ödənilməli olan pul təminatı ikiqat hesablanır.".
II. “Vətəndaşların pensiya təminatı haqqında” Azərbaycan Respublikası Qanununun (Azərbaycan Respublikası Ali Sovetinin məlumatı, 1992-ci il, N18, maddə 814; 1994-cü il, N15, maddə 177; 1995-ci il, N22, maddə 354; Azərbaycan Respublikasının Qanunvericilik Torlusu, 1997-ci il, N6, maddələr 453, 494; 1998-ci il, N1, maddə 10; 1999-cu il, N5, maddə 284; 2000-ci il, N6, maddə 379; 2001-ci il, N2, maddə 88, N3, maddə 145, N6, maddə 363, N12, maddə 736; 2002-ci il, N5, maddə 246, N6, maddə 328, N8, maddələr 463, 464; 2003-cü il, N1, maddə 16; 2004-cü il, N1, maddə 10, N2, maddə 60, N6, maddə 397, N8, maddələr 596, 598) 68-ci maddəsinin birinci hissəsinin ikinci abzası aşağıdakı redaksiyada verilsin:
"hərbi qulluqçuların döyüş şəraitində döyüş əməliyyatlarında iştirak dövrü (müvafiq icra hakimiyyəti orqanının qərarı əsasında) - ikiqat ölcüdə;". [^1]
III. Azərbaycan Respublikasının 1997-ci il 3 oktyabr tarixli 377-IQ nömrəli qanunu ilə təsdiq edilmiş "Hərbi xidmətkeçmə haqqında Əsasnamə"nin (Azərbaycan Respublikasının Qanunvericilik Torlusu, 1998-ci il, N1, maddə 14; 2001-ci il, N3, maddələr 138, 145, 146, 147, N12, maddələr 731, 745; 2002-ci il, N 6, maddə 328, N 8, maddə 464; 2004-cü il, N 2, maddə 57) 3 saylı əlavəsinin beşinci abzasının ikinci cümləsindən mötərizədə verilmiş "güzəştlə hesablandıqda " sözləri cıxarılsın.
IV. "Terrorçuluğa qarşı mübarizə haqqında " Azərbaycan Respublikası Qanununun (Azərbaycan Respublikasının Qanunvericilik Torlusu, 1999-cu il, N 8, maddə 475; 2001-ci il, N 11, maddə 676; 2002-ci il, N 5, maddə 258; 2004-cü il, N 3, maddə 133) 16-cı maddəsində "pensiyanın təyin olunmasında" sözləri "pensiyanın məbləğinin hesablanmasında" sözləri ilə əvəz edilsin.
V. Azərbaycan Respublikasının 2001-ci il 29 iyun tarixli 168-IIQ nömrəli qanunu ilə təsdiq edilmiş "Azərbaycan Respublikasının daxili işlər orqanlarında xidmət keçmə haqqında Əsasnamə"yə (Azərbaycan Respublikasının Qanunvericilik Torlusu, 2001-ci il, N 7, maddə 453, N 12, maddə 731, 2004-cü il, N 10, maddə 760) aşağıdakı dəyişikliklər edilsin:
1. 144-cü maddədə "25 il" sözləri "20 təqvim ili" sözləri ilə əvəz edilsin və mötərizədə verilmiş "imtiyazlı hesablama ilə" sözləri çıxarılsın.
2. 147-ci maddədə "25 il" sözləri "20 təqvim ili" sözləri ilə əvəz edilsin və mötərizədə verilmiş "o cümlədən imtiyazlı hesablama ilə" sözləri çıxarılsın.
VI. Bu qanun dərc edildiyi gündən qüvvəyə minir.
